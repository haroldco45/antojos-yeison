# Antojos de Yeison

Demo de app (PWA) para tomar pedidos de postres de fresa y llevar el registro de pedidos.
Hecha por Vibras Positivas HM.

- **Menú:** productos con fotos, cantidades y adiciones.
- **Pedido:** datos del cliente, domicilio o recoger, forma de pago y mensaje listo para WhatsApp.
- **Registro:** pedidos con hora de Colombia y estados Nuevo → Preparando → Entregado.

Precios y nombre del negocio son de ejemplo. Los pedidos se guardan en el celular donde se usa la app.

Publicada en: https://haroldco45.github.io/antojos-yeison/
